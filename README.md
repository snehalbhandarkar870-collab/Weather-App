## Project Name
Weather App using Python Tkinter

## Project Scope
This project is a GUI-based weather application developed using Python. 
The application allows users to enter a city name and fetch live weather information using an online weather API.

## Features
- GUI interface using Tkinter
- User-friendly design
- Fetches live weather data
- Displays weather details instantly

- Python
- Tkinter
